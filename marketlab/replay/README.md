# 金融时光机

从实验室的「金融时光机」进入，选择一个历史交易日、初始资金和回合长度，再点「开始回合」。交易日取自当前合法导入的行情快照。起始状态是在所选日收盘后的现金账户，可查看此前的日线。点击图表、使用方向键或日期选择器，可查阅已知的开高低收和成交量。上限为当前回放日。

- **下单和推进**　输入买入或卖出的整数份数，可以记下理由，再提交模拟订单。收盘时只登记意图，可在推进前撤单。推进到下一条真实日线后，按当天开盘撮合，再用当天收盘给资产估值。跳过交易所周末及休市日。数量超过持仓时不能卖出，开盘资金不足会拒绝整笔买单。也可单独记录观望理由。
- **播放与重置**　支持逐日推进、三档自动播放速度和暂停。操作交易表单或离开该模块会暂停播放。重新开始前会询问是否结束并保存旧回合。期满自动完成，也可以提前结束并撤销未成交订单。当前标签页刷新后可恢复同一快照的进度。
- **估值和成本**　资产净值 = 现金 + 持有份额 × 收盘价。每笔按成交额收取 0.10% 对称模拟手续费，买入开盘价上浮 0.05%，卖出下浮 0.05%。不配置杠杆、做空、税率、分红或利息；指数点位按乘数 1 进行教学模拟。最大回撤按历次收盘净值相对过去最高净值的最大跌幅计算。期末持仓按收盘估值，未收取虚构的平仓费用。
- **比较基准**　同额资金，从起始日后的第一个真实开盘以相同滑点和费率尽量买入整份，余下现金不计息。它与使用者的账户在同一收盘时刻估值。
- **AI 判断**　可选服务端分析仅接收市场标识和当前截止日，使用服务端按收盘时刻截断的历史行情和议息消息。开局不足 21 根已知日线时不调用。未配置服务时仍可离线完成所有模拟交易。训练过历史语料的语言模型未必能做到统计意义上的盲测，这些观点仅用于研究。切换日期后迟到的分析不进入当前日。
- **本机记录**　进行中的回合保存在当前标签页的 sessionStorage。完成后按回合 ID 去重归档到 localStorage 的 `ml.replay.runs.v1`，研究报告可读取 `report.facts`、`report.lines` 和 `report.notes`。同时保留模拟参数、数据快照、每笔交易、每项决策、日净值和已生成的 AI 判断。存储受限时，回合仍可操作，保存失败会有明确提示。建议使用固定的本机网址以稳定保留浏览器记录。未连接真实券商或真实资金。
- **静态集成**　先载入实验室的 `data/market.js`、`chart.js`，再加载 `replay/lab.js` 和 `replay/style.css`，调用 `window.MarketLabReplay.mount(container)`。统一工作台触发 `marketlab:navigate` 事件时，用模块 ID `replay` 表示当前可见。组件也返回清理函数供整体页面卸载。
- **自动测试**　在博客根目录运行 `node --test marketlab/replay/tests/engine.test.cjs`。涵盖真实快照回合、下一开盘成交、手续费滑点、交易日间隔、资产恒等式、基准、最大回撤、订单拒绝、取消及到期、禁止提前读取未来日线，以及研究报告字段。
- **公开消息截止**　观察资料库按具有时区的公告发布时间倒序显示最近三项。台交所按台北时间 13:30、沪深市场按北京时间 15:00 收盘过滤。未知市场保守取当日全球最早的零点（UTC+14），只有日期或没有时区的消息跳过。
