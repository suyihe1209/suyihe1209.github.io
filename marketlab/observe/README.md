# 市场观察的数据与计算

历史样本固定在 2023–2024 年。标的在自己的交易日历上显示原始日度收盘值或公布值。只包含真实记录，不补休市日、不复权、不合成成交量。台股加权指数为价格指数，0050、006207 为股票 ETF，00635U 为黄金期货 ETF。ETF 使用实际成交的台币价格，黄金基金包含期货展期与汇率影响。

## 原始来源与使用依据

- 金融監督管理委員會證券期貨局／臺灣證券交易所，2023–2024，「盤後資訊 > 個股日成交資訊」（11549）与「發行量加權股價指數歷史資料」（11755）。摘取 TAIEX、0050、006207、00635U 各 481 个交易日。ETF 成交量以份计；指数有开高低收。两个数据集均依政府资料开放授权条款第1版公开，使用者遵守条款并保留署名即可使用。[个股](https://data.gov.tw/dataset/11549) · [指数](https://data.gov.tw/dataset/11755) · [授权](https://data.gov.tw/license)
- 中央銀行／台北外匯經紀股份有限公司，2023–2024，「銀行間市場新臺幣對美元收盤匯率」（7232）。使用两年度的逐日公开表，共 492 日，每一美元兑换多少新台币。保留外汇市场有报价的周六。此数据集依政府资料开放授权条款第1版公开。[开放数据与许可](https://data.gov.tw/dataset/7232) · [2023 原表](https://www.cbc.gov.tw/tw/cp-2151-165071-58ddd-1.html) · [2024 原表](https://www.cbc.gov.tw/tw/cp-2151-178553-efe4c-1.html)
- U.S. Department of the Treasury，2023–2024，Daily Treasury Par Yield Curve Rates。取财政部根据行情估算、发布的10年期名义平价收益率 BC_10YEAR，共 500 个工作日，单位为年化百分数。使用财政部官方计算结果的数值；美国联邦政府作品适用美国版权法 17 USC §105，未复制第三方图件或商标。[方法](https://home.treasury.gov/policy-issues/financing-the-government/interest-rate-statistics) · [政府作品依据](https://uscode.house.gov/us/usc/t17/s105/)
- Board of Governors of the Federal Reserve System，2023–2024，16 篇预定 FOMC 会议声明。以美东时区保留正式公布时刻（夏令时 UTC−4、冬令时 UTC−5）。列表、摘要和分类由本工具根据各次声明生成。每条记录带独立原文链接。美联储理事会说明其自行发布且未特别标注的资料属公共领域，可以署名复用。[会议与原文](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm) · [版权声明](https://www.federalreserve.gov/disclaimer.htm)

## 图表与政策分类

- 每个标的分别展示原单位和区间首末观测值变化。价格、指数和汇率使用收盘比值减一；国债收益率使用年化百分数之差乘以 100，得到基点。
- 比较两项标的时，先求两套日历的交集。每一对相邻共同日期组成一个区间，两边使用完全相同的首尾日期，再对各自的区间变动计算皮尔逊相关系数。跨假日的变动可以涵盖数个日历日。不同市场的日收盘时刻不同，这个统计用于描述共变动。
- 二维矩阵中每个单元格独立对齐两项资产。在 20、60 或 120 个共同区间的滚动窗中，只有收满窗口才产生结果。任一列为常数时留空。
- 新闻中的政策语气依据声明明确写出的决定动词。raise、maintain、lower 分别表示加息（偏紧，+1）、维持（持平，0）、降息（偏松，−1）。决议目标区间从同一句原文提取。分类描写当次政策行动，不推断市场涨跌、声明其他措辞的倾向或投资者心理。时间条保留每次公告，列表支持语气筛选。
- 「保存到实验记录」将当时的参数、共同区间数、总体与滚动相关、逐条入选决议及来源保存在当前浏览器。研究报告可使用该固定快照。

## 复现

从本目录运行以下命令。使用 Python 3.9 或更高版本的标准库及系统 IANA 时区数据。行情与决议按各自官方入口获取；可通过原件缓存离线重建。006207 的每日数据取自同一项目 data/source.csv，其独立复现说明在相邻目录。生成器会验证标的、日期排序与覆盖、OHLC 范围、官方声明文本和美东时区。每个行情序列的 sha256 使用 Python 的紧凑 UTF-8 JSON 对日线数组计算。

```sh
python3 reproduce.py --cache /tmp/marketlab-official --output assets.js
python3 reproduce.py --offline --cache /tmp/marketlab-official --output assets.js
node test-market.cjs
```

主标的支持逐日查数及 5、20 个实际观测日的变动和简单移动均值。有 OHLC 的标的可在日、周、月 K 线间切换，每个周期按实际记录聚合开高低收和可用成交量，首末周期只覆盖已选日期范围。无 OHLC 的序列保留原单位数值曲线。
