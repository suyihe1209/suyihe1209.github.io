# 正式前瞻 · 本机服务记时

预测擂台保留三种独立记录。历史盲测和最新快照跟踪继续存在浏览器本机数据库。正式前瞻经本机 HTTP 服务锁定写入 SQLite，使用服务时钟盖时，单列排行榜。浏览器的历史记录无法转为正式成绩。

## 如何参加

在本机双击实验室目录的「导入沪深300.command」、「导入标普500.command」或「导入纳斯达克综合.command」，选择自己有权使用、与所选指数相符的 OHLCV 日线 CSV、数据来源、实际许可和成交量单位。需要至少 85 根连续且已收盘的真实交易日数据。生成的专属快照可用「打开这份快照.command」启动，详细步骤见[沪深300本机导入](模型与复现.md)。打开「预测擂台」中的「正式前瞻」。内置的 006207 ETF 是归档历史行情，不能参与该组。

沪深300 使用上海时间，窗口从最新真实交易日 15:00（含）起，至紧接着的**次日历日** 09:15（不含）。这是一项保守的实验规则，周末和假期不延长。申报时该期最终日线须已导入，快照最新交易日与申报截止一致，频率基准和逻辑回归也须已经生成。沪市常规开盘集合竞价从 09:15 开始、收盘集合竞价在 15:00 结束，供核对。[上交所交易时间](https://english.sse.com.cn/start/trading/schedule/)

在打开窗口内，检查行情、输入 0—100% 的上涨概率和可选理由，确认来源与连续性，再点击「提交正式前瞻预测」。一台服务对应一个匿名参赛者。每个市场分别存储、结算并排名。唯一键由市场、截止交易日、五日周期组成，重复或并发提交会被拒绝。概率、理由、本机服务时间、收盘点位、模型版本和当时两项量化概率同时冻结。服务器从快照读取数据，客户端不能自填提交日期、量化结果或结算值。

配置有真实 AI 服务时可在锁定人工判断后点击「加入同期 AI 判断」，该动作可能计入服务商费用。对相同输入已有的有效同期 AI 缓存可免费复用。在同一窗口内、同一快照上单独从预测擂台生成的分析也可归入本期。AI 的生成时间和接纳时间必须在窗口内。服务未配置时仅记录人工与量化参赛者，不生成 AI 概率。

美国标普500（SP:SPX）和纳斯达克综合（NASDAQ:IXIC）使用纽约当地时间和 IANA 夏令时规则，正式窗口从近一交易日 16:00 开始，至次日历日 09:30 前。提早收市日也统一等至 16:00 才接收正式判断。每次结算仅查该市场实际后续五根日线。2023—2028 年的 AI 消息截止使用经核对的美股开市日标准收盘 16:00 或半日市收盘 13:00。其他年份的历史 AI 分析保守仅采用纽约当日 13:00 前的消息。只有发布日期的中国消息按北京时间当日 23:59:59 处理。[NYSE 当前交易日历](https://www.nyse.com/trade/hours-calendars) · [NYSE 2023–2025 提早收市日历](https://ir.theice.com/press/news-details/2022/NYSE-Group-Announces-2023-2024-and-2025-Holiday-and-Early-Closings-Calendar/default.aspx)

## 结算与边界

在同样的本机服务记录目录下导入含有后续行情的新快照，打开正式区或点「刷新状态」。若从该市场截止日往后已有五根连续交易日记录，且第五日已收盘，服务按当日收盘与冻结的起点比较。严格上涨记 1，持平或下跌记 0，Brier 分为（预测概率 − 实际结果）²，越小越好。已结算行不覆写。记录包含五个观测日期、期末数值、结算时间及快照指纹。源文件修订起点点位将保留原预测并等待口径一致的数据。各参与者只统计其实际有预测的已到期样本。

本机以导入文件为行情及交易日顺序依据，来源和完整性由提供者核实。文件指纹能辨别输入变化，不能认证数据供应商、交易所节假日或系统时钟。拥有这台电脑的人可以修改时钟、行情或 SQLite 文件。这些是单机服务盖时的研究记录，未经第三方见证。静态网站不会运行此接口。公开多人比赛还需要身份校验、可信数据与时钟、访问控制和防刷审核，此本机实现只在回环地址监听。

## 接口与验证

- `GET /api/marketlab/official` 可带 `?marketId=CSI%3A000300` 、`?marketId=SP%3ASPX` 或 `?marketId=NASDAQ%3AIXIC`。默认按启动快照查询。返回 gate、records、ranking、aiConfigured，并对已到期的旧记录尝试结算。
- 同源 `POST /api/marketlab/official` 接收 `{marketId,cutoff,probability,reason,confirmedReal:true}`，概率为 0 至 1。错误截止、关窗和重复提交返回 409。
- 同源 `POST /api/marketlab/official/ai` 接收 `{marketId,cutoff}`，沿用实际模型的限额、缓存与无密钥行为。
- 服务数据库为 `MARKETLAB_CACHE_DIR/official.sqlite3`，默认位于当前用户的 `.marketlab`。不同快照可对同一份记录进行后续结算。
- 从博客根目录运行 `python3 -m unittest discover -s marketlab/tests -p test_official.py` 可验证新鲜度窗口、并发唯一性、防止客户端伪造时间、实际第五日结算、跨市场隔离、AI 同期配置与封存等情况。


## 多市场快照与本机服务

预测接口按请求内的市场标识选择实际行情。不存在对应标的时返回 404。附加 HTTP 头 `X-MarketLab-Snapshot` 并给出客户端的行情指纹，可检查同一市场的版本是否匹配。可用 `GET /api/marketlab/snapshot?marketId=SP%3ASPX` 获取当前服务实际选择的数据。

同一标的优先使用显式 `--snapshot` 的自行导入快照，随后依次选取 `--extra-snapshot` 注册的其他导入、本机研究缓存和站内已有的同标的归档。缓存位置为 `~/.marketlab/markets/cn/market.json` 、`us/market.json` 或 `nasdaq/market.json`，可通过 `MARKETLAB_MARKETS_DIR` 指定其他根目录。服务对缓存核对市场标识和时区，本机研究缓存、站内归档及台湾 ETF 均不会自动取得正式提交资格。要同时使用两份已授权独立导入，运行 `python3 marketlab/server.py --snapshot "/路径/沪深300快照" --extra-snapshot "/路径/标普500快照" --open`。

`GET /marketlab/markets/local.js` 仅导出本机固定目录的研究缓存和显式导入快照，不允许任何路径参数。页面或报告的公开分发仍须遵守各自的行情许可。
