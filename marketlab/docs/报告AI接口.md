# 研究报告的 AI 摘要

研究报告先在浏览器冻结各模块已有的数值、原文及风险说明。配置本机 AI 服务后，报告接口支持让语言模型选择和排列这些事实。显示时仍由浏览器逐项查找原文，计算结果、来源和单位来自已保存的实验记录。未配置密钥时可以继续使用原始报告。

本机工作台同源发送 `POST /api/marketlab/report`，使用与预测 AI 相同的 `MARKETLAB_AI_KEY`、`MARKETLAB_AI_MODEL` 和可选的 `MARKETLAB_AI_BASE_URL`。调用配置的模型服务可能按用户账户计费。模型收到报告标题、事实和风险条目，请选择适合发送给该服务的报告。

请求体示例：

```json
{"title":"交易回合复盘","facts":[{"id":"F1","text":"本次回合的初始模拟资金为 100000 TWD。"}],"risks":[{"id":"R1","text":"此回合使用历史价格，不能验证未来表现。"}]}
```

请求上限为 64 KiB。标题最多 180 个字符，必须有 1 至 48 条事实，可以有 0 至 20 条风险。每项的 text 为 1 至 800 个字符。ID 因清单而唯一，支持 1 至 64 个 ASCII 字母、数字、冒号、句点、下划线或连字符。

成功时 JSON 对象有 `summaryIds`、`riskIds`、`model`、`version`、`generatedAt` 五个字段。前两项是有序 ID 数组，后面三项是配置的模型、服务商实际返回的模型版本和服务端生成时间。模型必须选取 1 至 8 个现有事实 ID，最多选取 5 个风险 ID，风险候选非空时至少选取 1 个。重复、越界、跨清单、附带额外文本字段均拒绝，未通过校验的响应不会作为研究报告保存。

两种 AI 接口共享一个在途请求名额、5 秒调用间隔和滚动 24 小时 20 次的本机调用限制。相同标题、原文、ID、排序、模型地址、模型及提示词版本可以命中同一已验证缓存，复用结果保留第一次生成时间。HTTP 400 表示输入无效，413 表示内容过大，429 表示请求过于频繁，502 表示外部模型失败或未返回有效 ID，503 表示未配置或服务暂不可用。访问来源和内容类型也必须符合本机服务要求。

从博客根目录运行 `python3 -m unittest discover -s marketlab/tests -p test_report.py`，可在离线环境检验报告编排、缓存、与预测接口共用额度，以及帮助文档的读取。
