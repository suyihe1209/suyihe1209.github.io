# 五个交易日方向实验

在市场交易日 T 收盘以后，回答「第五个后续交易日的收盘价格是否高于 T 日收盘价」。两者相等记作未上涨。价格变动取自同一标的和同一价格口径。这里预测收盘价格方向，不计分红及费用，也不模拟交易收益。

## 如何复现

在 MarketLab 目录内使用 Python 3.12 创建隔离环境。首次安装科学计算依赖需要网络，日常使用网页或重新打开已生成快照均可离线。

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r model/requirements.txt
.venv/bin/python model/train.py
.venv/bin/python -m unittest discover -s tests -p test_model.py
```

默认读取 `data/source.csv` 和 `data/source.json`。也可以运行 `python model/train.py --csv 市场.csv --meta 来源.json --out 输出目录`。先在新目录生成、验证，再整体替换网页的数据目录。保存当次的源文件、元数据及导出物即可保留独立实验记录。无训练依赖的网页读取预生成的 `data/market.js`；本地 HTTP 服务读取同内容的 `data/market.json`。

## 数据边界

- 行情供应商遵守 `model/providers.py` 定义的 `BarProvider.load()` 接口。内置适配器接收 UTF-8 日线 CSV，表头为 `date,open,high,low,close,volume`。日期采用 YYYY-MM-DD，按交易日严格递增；重复日期、无效值、错误的高低价直接报错。价格每项必须大于零，成交量可为零，未提供的成交量须留空。不会填补停市日或凭空补价。
- 元数据必须包含市场名称、标识、时区、币种、价格和成交量单位，以及数据来源、链接、许可、样本截止日、带时区的更新时间和历史演示标记。CSV 校验能发现日期重复或乱序，不能单凭价格识别供方漏发的一整个交易日。接入其他数据时应先按对应交易所日历核对完整性，且始终维持相同的价格与成交量口径。
- 若使用交易所交易基金（ETF）作为研究标的，概率和结算都属于该基金的收盘价变化。底层指数走势、币种及休市日可能不同。基金除息也可能使收盘价下移。

## 两个模型与验证

1. 在时点 T，以当日及以前的收盘价计算 1、5、20 个交易日收益率，收盘价相对 5 日和 20 日简单均线的偏离，以及最近 20 个单日收益率的标准差。波动率按日计算，分母取样本数。最初 20 行只供指标预热。
2. 训练起点 S 最晚取 T 前第 5 个交易日，因为 S 的标签恰好在 T 收盘揭晓。紧邻预测日而标签尚未揭晓的起点均不参与拟合。只用最近最多 252 个已到期且特征齐全的样本，至少需要 60 个；只有单一类别时，无法拟合逻辑回归，当日不出两模型对照。
3. 频率基准取训练样本中五日后上涨的比例。逻辑回归先用同一训练窗拟合标准化器，再以 L2 正则化训练，C=1、LBFGS 求解，最多 500 次迭代。两者各自输出 0 到 1 的上涨概率，无独立概率校准。
4. 逐日向前滚动，每个起点重新拟合并保存概率、训练起止日期、标签可见截止日及样本数。所有参数预先固定。这里是连续的逐日前推验证，后面窗口会合理使用较早、已到期样本，没有随机划分或测试集调参。[scikit-learn 时序划分说明](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)
5. 对每个已到期预测用第五个后续交易日的实际收盘价结算。概率达到 50% 即判涨，方向命中率为正确次数除以结算次数；Brier 分数是「预测概率减实际标签」的平方平均，越低越好。最后五根尚未到期的记录不计分。相邻预测窗口高度重叠，样本数不能当作彼此独立的观察次数。

## 审核实验

打开 `data/market.json` 的 `experiment` 可核对模型版本、实际训练环境、行情指纹、参数、逐日前推验证区间以及两个模型的命中率和 Brier。每条 `forecasts` 都有训练窗口，可针对任一天从 CSV 截断到当日重跑核对。前端展示的分数属于历史验证。研究快照没有启用真实资金交易，也不能证明有人在过去提交过预测。

## 随附快照的结果

本次使用复华沪深300 ETF（006207）于 2023-01-03 至 2024-12-31 的 481 根真实日线。共生成 397 次逐日预测。2023-05-19 至 2024-12-24 的 392 个预测起点已有五日后收盘价，其余 5 个起点留待后续行情。

- 频率基准预测正确 216 次，命中率 55.10%，Brier 为 0.2522。
- 逻辑回归预测正确 178 次，命中率 45.41%，Brier 为 0.2811。这个区间里，逻辑回归在方向和概率误差两项均逊于频率基准。
- 2024-12-31 收盘预测使用 2023-12-11 至 2024-12-24 的 252 个训练起点，这些标签在当日全部揭晓。它属于尚未结算的五个起点。

## 导入自己的沪深300指数日线

Mac 上双击 MarketLab 文件夹中的「导入沪深300.command」，在访达先选 CSV，再选保存位置。随后填入提供方名称、官网或数据页面、实际获准的使用范围、成交量单位。工具自动训练，在所选位置新建独立快照并打开工作台。下次双击快照中的「打开这份快照.command」即可回到同一浏览器地址。该启动器会使用原站目录的本机服务；移动了整站之后，可以用下方命令指定新的服务位置。

CSV 至少需包含 85 个完整交易日，建议一年以上，并有已到期的上涨与未上涨样本。先向提供方确认文件包含该指数从起日到止日的全部收盘交易日，且成交量口径一致。支持 UTF-8（含 BOM）和 GB18030；可用日期、开盘、最高、最低、收盘、成交量等中文列名或英文标准列名。支持 YYYY-MM-DD、YYYY/MM/DD、YYYYMMDD。仅有倒序时会转换为升序。如有证券代码列，会校验是否为沪深300。只有 OHLC、没有量时，可填写「未提供」；指数点位和 ETF 基金价格属于不同研究标的，须分别导入。授权信息将与结果一起保留在所选目录中，导入过程不上传文件。

其他系统可使用已装依赖的 Python 运行下列命令，将示例中的路径、单位和数据来源换成自己的实际信息，目标文件夹需尚未存在。

```sh
python model/import_csi300.py --csv "/path/沪深300.csv" --output "/path/沪深300研究快照" --source-name "数据提供方名称" --source-url "https://example.org" --license "实际获准的使用范围" --volume-unit "手"
python server.py --snapshot "/path/沪深300研究快照" --port 8766 --open
```

新快照中的 `source.csv` 为已校验的标准英文表头，`source.json` 记录用户提供的来源、授权、成交量单位、导入时间、原文件与规范化文件指纹。两份预计算的网页数据保留模型版本和结算验证成绩。随站附带的 ETF 历史示例照常保留。
