# MarketLab 产品与任务清单

用户是学习金融与人工智能的研究者。六项功能共用的入口是博客首页和小工具集合中的「AI 金融市场实验室」。访客可以匿名从一根已收盘的日线出发，对第五个后续交易日的收盘价作出概率判断，由程序保存、对比和结算。上涨指严格高于起始收盘价。所有结果用于研究与学习。

## 第一阶段验收顺序

1. 保存原站及三个已有工具的可恢复版本，添加工作台入口。
2. 核实行情的供方、许可证、观察对象、时间范围及成交量单位。实现可替换的日线导入和数据校验。
3. 按时间训练基准和逻辑回归，冻结预测概率，记录各截止日可使用的样本和模型版本。
4. 实现 K 线、匿名判断、观点比较、到期结算、历史成绩，以及空数据、失败和过期提示。
5. 接入可选的本机 AI 服务，限制请求频率并检查输出，未配置时保留量化和人工流程。
6. 测试数据边界、历史盲测、重复操作、浏览器重开、手机交互和原站入口，记录验证范围。

## 已接入工作台的其余阶段与验收标准

|阶段|用户可以完成的任务|验收条件|
|---|---|---|
|二 · 量化研究|选择指标、训练段、验证段、趋势评分、逻辑回归或随机森林，比较均线交叉、动量和持有策略|独立时间验证，次一可成交时点执行，明确费用、滑点，核对收益、交易数与最大回撤|
|三 · 金融时光机|选择起始日，逐交易日推进、暂停、模拟买卖并复盘|当前日之后的价格与新闻均不可见，现金与持仓逐笔守恒，可对照买入持有|
|四 · 市场观察|比较股票、黄金、汇率、债券和有授权新闻的情绪|核对许可证、交易日历、单位和收益对齐，显示窗口与有效样本数|
|五 · 宏观沙盘|调整利率、通胀、增长和风险偏好，比较两组情景|记录假设和参数，区分统计关联与因果结论，同一输入可复算|
|六 · 研究报告|保存实验快照、回看并导出含图表的报告|归档标的、输入版本、各方观点、真实成绩与局限；导出数值可追溯至原记录|

六项功能可从同一总览进入。观察、预测、回测、回合与宏观情景均可作为已保存研究报告的来源。正式前瞻采用本机服务器时钟，独立于历史练习排行。详细测试见[验收记录](验收记录.md)。上线、数据账户、付费服务及线上存储另行审批。
