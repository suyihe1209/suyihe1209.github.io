# MarketLab 六项核心功能验收记录

## 2026 年 11 月 18 日网页版

从博客首页进入，依次切换沪深300、标普500与纳斯达克综合。三个指数的末日收盘分别为 3983.77、7323.63 和 24429.88 点。在本机预览以及新的静态站访客会话中，分别核对了最后一根日线、预测截止、量化标的、时光机回合和观察页。三个指数都以实际交易日训练；冻结日之后的新闻和日线不会进入网页回放。公开站的首次行情从用户设备向来源请求。本机预览另可使用个人研究缓存。

## 早期版本的基础工作台与原站

- 首页和小工具集合都能打开同一个工作台。跟踪沪深300的 ETF 示例具有交易所真实日线、许可说明和币种，与导入的指数点位区分。
- 台交所 24 份月报重建 481 行；独立分发渠道返回的同区间 OHLCV 逐值相符。冻结快照中已到期的 392 个起点逐日评估，见模型说明。
- 导入器识别中文或英文表头、交易代码、日期与量的单位。它在独立目录训练，不覆盖原示例。模型测试包含未来数据扰动、平盘、节假日与五根日线的结算边界。
- 桌面 Chrome 和模拟触屏宽度 320、375、768 像素通过。图表可切换 5、20、60 日，查阅窗口的每个日期均不晚于所选截止日。
- 浏览器验证 0% 与 100% 两个端点，拦截负数、超范围及空输入，锁定后禁改。刷新保留概率、理由、模型概率与结算记录。测试环境向数据末端追加五根日线，等待中的记录自动结算一次。
- 在无 AI Key 的正常入口验证未配置提示。使用测试响应验证有效结构、缺字段、外部失败、缓存复用、请求限额和截至指定日期构造输入。测试响应仅存在于测试进程中。
- 从工具集合实际打开原有 CS2 匹配器并试算，确认 T800 载入三维模型，下载两份安卓 APK 并逐字节核对文件指纹。
- HTTP 预览仅允许本机地址与同源 API 请求。程序源码与版本控制目录不通过专用预览服务分发。

## 早期版本的六项核心功能验收

1. **市场观察**。六组真实行情按各自日历和单位展示，日、周、月 K 线、5 日和 20 日指标可切换。仅有公布值的收益率使用基点变化。检查六资产相关矩阵、共同观测区间、20 期滚动相关、缺值和常数序列。16 篇美联储声明均有发布时间和原文链接，筛选 2024 年的偏松决议得到 3 篇。可保存所选资产、区间与政策消息。
2. **预测擂台**。浏览器练习、最新快照跟踪与本机服务记时的正式前瞻可分别查看。核验了有效窗口内锁定、并发重复提交、过期快照拒绝、交易日跨周末、第五日收盘前不得结算、重复刷新不增加成绩、晚到的 AI 结果不能追加入榜。正式组正向流程在隔离测试中使用受控时钟，默认历史 ETF 从普通界面进入时只开放练习。详见[正式组规则](正式前瞻.md)。
3. **量化研究**。在不同训练与验证区间实际拟合趋势评分、逻辑回归和随机森林。核验模型在修改未来价格后不变、训练标签在训练截止前已揭晓、均线与动量等信号只在下一开盘成交、手续费、滑点与资金净值恒等式。用独立 Python 实现核对一次实验的 141 个样本外逻辑回归概率及 146 日策略净值；概率最大绝对差小于 0.000000009，净值在复核精度内一致。四个有开高低收的资产可回测，汇率和收益率可验证方向。
4. **金融时光机**。用实行情验证回放、暂停、买卖、撤单、资金不足、期末估值、基准和回合归档。按原始新闻时区验证美联储 2024-09-18 决议在当天台股收盘时尚不可见，直到下一交易日才出现。预测 AI 的历史输入也按收盘时刻筛选；90 天内无可用消息时按空清单处理。
5. **宏观沙盘**。验证两组相同条件的差异为零，分别改变利率、通胀、增长和风险偏好，复算债券平价及实际购买力。两市历史月度参考取共同最后报价，不跨过缺失的月份。保存后能在报告中还原 A、B 参数、估值、相对变化与图表。
6. **研究报告**。从各模块真实保存记录生成综合报告、单项报告，核对 HTML 自带图表、JSON 保留实验依据、刷新后能重读同一报告。无密钥时结构化报告仍可生成；测试进程用受控响应验证 AI 只能选择实际存在的事实与风险。另验证只有汇率收盘价的模型报告带逐日样本外概率图；综合提要的事实与风险逐章入选，模型成功返回但本机存储已满时依然可以直接导出。预览服务、直接双击文件两种方式均实测。浏览器触屏模拟覆盖 320、375、768 像素宽度，通过六个入口，可实际运行量化与导出报告。

本次 Python 测试 27 项、JavaScript 模块测试 15 项均通过，另运行原站回归和六模块浏览器流程。

## 复验方法

在博客根目录运行下列命令。Python 3.12 的科学计算依赖见模型目录，Mac 已安装的解释器入口是 `~/.marketlab/model-python`。

```sh
~/.marketlab/model-python -m unittest discover -s marketlab/tests -p 'test_*.py'
node --test marketlab/quant/test_engine.cjs marketlab/replay/tests/engine.test.cjs marketlab/observe/test-market.cjs marketlab/scenario/test_model.cjs
python3 marketlab/server.py
```

另开一个终端，在安装了 Playwright 和 Chromium 的环境分别运行 `node marketlab/tests/browser.cjs` 、`node marketlab/tests/suite_browser.cjs` 和 `node marketlab/tests/regions_browser.cjs`。可用环境变量 `CHROME_PATH` 指向现有 Chrome，`MARKETLAB_URL` 指向其他本地端口。浏览器测试使用新的临时会话，不改变访客自己的预测记录。
