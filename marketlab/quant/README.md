# 量化研究中心

在工作台选择「量化研究」，指定研究标的、预测期限、指标、训练与验证日期、模型和策略，再运行实验。每次运行均依照所选历史数据真实拟合或计算。模型输出与交易策略彼此独立，例如可以用随机森林验证涨跌方向，同时回测均线交叉。选择「模型概率择时」才会把该模型信号传给交易策略。

## 数据与验证

价格特征均用截至当日收盘可见的数据。收益率和动量为相对收盘变动，均线偏离度为收盘价除以当期均线减 1，20 日波动率为最近 20 个单日收益率的总体标准差。预测日后第 H 个交易日收盘价严格高于起点才计上涨。所有指数和基金使用各自观测到的日历；现金分红及未提供的复权信息不会另行加入基金价格收益。

只有标签在训练截止日或之前已揭晓的样本可用于拟合，且至少需 30 个完整起点。标准化的均值和标准差只在训练样本内计算。验证结果仅采用独立时段内已到期的标签。验证允许使用训练期末及验证期早期的历史收盘信息计算当时指标，始终不会读取信号之后的价格。用户根据看过的验证结果调整参数会使该窗口成为探索性验证，要评估选定方案应使用新窗口。多日预测相互重叠，观察次数不能等同独立样本数量。

## 三种模型

- 自定义趋势评分对选中指标做训练窗标准化，计算权重加权和，再除以权重绝对值之和，最后用逻辑函数映射到 0–1。每项权重均可调，负值表示反向关系。这个分数没有独立的概率校准。
- 逻辑回归最小化二项负对数似然加 L2 惩罚，惩罚项为斜率平方和除以 2C，截距不受惩罚。浏览器以牛顿法、线搜索及正则化 Hessian 拟合训练样本；全程不调用网络。
- 随机森林为真实训练的分类树集成。每棵树对训练集作等容量有放回抽样，每个节点随机选择最多 floor(√特征数) 个特征，依 Gini 不纯度选择有效的切分点。最少叶子样本数为 4。预测取所有叶子上涨频率的平均，种子固定为 1729，可调树数与深度。独立 Python 版使用 scikit-learn 的标准随机森林；随机数发生器、平局和切分实现不同，预测无需逐点相同。

方向分界取 50%；Brier 分数取预测概率与 0/1 实际标签的平均平方误差。频率基准只使用训练窗已到期标签的上涨比例。三种模型均无概率校准保证。

## 交易与风险口径

有完整开高低收的资产可回测。收盘后判断次日目标持仓，下一交易日开盘成交。均线交叉策略在短均线高于长均线时持有；动量策略在回看期收盘涨幅为正时持有；模型择时在分数达到所选阈值时持有。买入持有对照在验证首个交易日开盘买入，并使用完全相同的费用与滑点。只有收盘价的资产仅做方向检验。

本金固定为 10,000 单位，允许小数份额，全仓或现金，无杠杆、卖空或现金利息。买入执行价 = 开盘价 × (1 + 单边滑点)，卖出执行价 = 开盘价 × (1 − 单边滑点)，成交额另计单边费用。1 基点为 0.01%。每日按收盘价估值，验证结束仍持有的仓位不强制变现。净值以本金为 1。最大回撤按净值相对历史高点的最大跌幅计算，初始本金也是高水位。成交次数按买单与卖单分别计数。年化波动率以日收益样本标准差 × √252 粗估，夏普比率采用零无风险利率；单日样本或零波动时不估夏普。指数点位按可交易组合近似，所得是研究性的策略净值。

## 留存与复核

结果含样本起讫、验证概率、逐日净值与回撤、信号日期、成交价格与费用、行情来源、模型版本及配置。保存在当前浏览器的 `ml.quant.runs.v1`。通过「下载本次实验 JSON」留存独立副本，市场数据需一并保存。在 MarketLab 目录运行下列命令可用已安装的科学计算环境核对实验。另一个市场可通过 `--csv` 指定其原始数据。

```sh
node --test quant/test_engine.cjs
python quant/reference.py --config 实验记录.json --csv data/source.csv --out 复核结果.json
```

数值验收使用 006207 真实行情。以 2024-01-16 为训练截止、2024-01-17 至 2024-08-27 验证、5 日预测、C=1 的逻辑回归，检验 141 个到期预测。浏览器与 scikit-learn 逐次概率的最大绝对差为 0.000000009 以内。5/20 日均线策略在单边 5 基点费用与 5 基点滑点下成交 10 次，两个独立实现的逐日净值一致。预设指标为 1 日收益、5 日动量、20 日均线偏离及 20 日波动率，此组数据用于验收算法。
