# MarketLab 安卓版

从首页的「工具箱 → AI 金融市场实验室」下载安装包，在 Android 8.0 或更高版本的手机安装。安装页若询问是否允许该浏览器或文件管理器安装应用，按手机提示操作。保持系统 Android WebView 为现代版本，第一次打开时连接网络。在「今日」点「更新行情与消息」，完成后打开「研究台」。

## 使用

- **今日**显示沪深300、标普500、纳斯达克综合指数的已收盘日线及对应的官方消息。各市场保留自己的交易日、时区、行情来源和原文链接。缓存更新时间是设备读取资料的时间。交叉核对失败会单独列出。断网时仍可查看已缓存内容。
- **助手**支持普通聊天、连续追问，也能根据问题读取行情和核对公开来源。先到「设置」选择厂商，应用自动填入官方地址。从下拉框选支持工具调用的对话模型，再输入当前厂商的 API Key 并保存。「从当前账户读取模型列表」可刷新可见模型。也可使用指定的自定义地址，或手动填写控制台中的部署 ID。回答下面的「查证来源」会打开外部浏览器。未配置时仍能更新公开行情和消息。
- **设置**默认开启联网每日补采，默认当地时间 8 点起由安卓择机执行。可改为 0 至 23 的整点。省电限制、网络、强制停止和厂商后台策略都会影响实际执行时刻。系统任务在联网后可再次运行；重新打开应用时也检查已错过的更新。每日自动 AI 简报需要单独勾选，默认关闭。
- **用量**分别显示今天的手动提问数和模型调用数。App 不设每日上限，服务商的收费和限流规则继续适用。重复查证会自动收束。
- **研究台**提供市场观察、预测擂台、量化研究、金融时光机、宏观沙盘和研究报告。连接过网络并成功缓存指数日线后，可在离线时使用这六个模块。选择研究市场后，模型在设备上计算。新行情抵达时点顶栏的「载入新行情」才会重新打开当前研究页面。记录保存在此 App 沙盒中，报告可选择 HTML 或 JSON 并用系统文件选择器保存。桌面盖时的正式前瞻需另开本机服务。
- **凭据与文件**的模型地址、模型名、用户密钥在本机使用 Android Keystore 的 AES-GCM 加密保存。密钥栏不回显原值，留空沿用，点「清除模型配置」删除。用户密钥只随用户配置的 HTTPS 模型请求发送。公开行情与新闻发布者在网络更新时收到正常请求。卸载应用会清除设置、研究记录与行情缓存，已另存的报告仍在用户选择的位置。

## 模型调用和错误提示

厂商下拉框包含 GPT、Claude、Gemini、Grok、Meta Muse、DeepSeek、Kimi、豆包等官方服务。应用使用同一个已保存的厂商和模型处理手动问答与每日简报。自定义地址可填服务基础地址，或该服务明确支持的完整对话接口。支持 OpenAI Chat Completions、Responses 和 Anthropic Messages。市场查证需要工具调用权限，账号可见的模型也可能只有生成文本或其他用途。

发生 HTTP 404 时，可在设置核对实际请求地址，再读取当前账户模型或选取控制台提供的 ID。模型不存在、未开通、接入点填错和网关路径错误的处理方式不同，助手会根据服务商返回的错误类型提示。401 对应凭据问题，403 对应权限或地区限制，429 表示访问频率或账户额度受限。

## 本机构建与签名

需要 Android SDK Platform 33、Build Tools 33.0.2、JDK 17、Python 3 和 zip。编译项目使用本机现有 SDK，无需下载 Gradle 依赖。通过 `ANDROID_HOME` 和 `MARKETLAB_JAVA_HOME` 可指定工具位置。

在 marketlab 目录运行 `./android/build.sh`。它从公开工作台白名单打包资产，以已建立的本机发布证书签名，并验证 APK v2/v3 签名。输出为 `downloads/MarketLab-Android.apk`。只构建时用 `./android/build.sh --unsigned`，稍后可用 `./android/build.sh --sign 已对齐的APK路径` 签署。

1.2 可用原签名覆盖安装 1.0 或 1.1，保留加密设置与研究记录。旧版每日请求上限自动失效。新对话按服务和地址分别保存在本机，每组保留最近 40 轮，提问时携带其中最近最多 12 轮、24,000 字的上下文。

更新必须使用同一签名。首次构建时为此 App 建立的更新证书和随机口令存于用户目录 `.marketlab/android-signing/`，只有本用户可读。请将该目录作为私密文件备份至安全位置，切勿放进博客下载或公共仓库。复制项目不会同时复制更新签名。可用 `MARKETLAB_ANDROID_SIGNING_DIR` 指定已备份的目录。如更换发布证书，系统不能覆盖既有同包名安装。

`app/src/main` 是正式应用。包名 `cn.zijing.marketlab`。APK 只含公共网页、公开参考序列、安卓界面和程序，三只指数的本机行情在使用者自己的设备联网后建立。手机用户的模型凭据、专属行情文件、本机发布私钥均不进入安装包。

## 复验

`engine-tests/run.sh` 测试行情与消息解析、来源校验、模型工具与调用计数。可在真实联网环境按该脚本的提示运行数据源检查。`device-tests` 提供用于专用模拟器的同签名测试程序，可在目标已缓存行情后用飞行模式逐项验证六个研究模块。它会在模拟器中保存研究实验和报告；请勿用于存有个人记录的手机。为打开导出的报告，在系统文件选择器里选择保存位置。

本版实际覆盖安装于 Android 13 ARM64 模拟器。未连接实体手机，厂商系统长期省电策略及使用者账户的真实付费模型结果取决于该设备与服务商。

在专用、已联网补完三指数的模拟器上复验时，从 marketlab 目录执行下列步骤。测试程序必须与被测 App 同签名才可驱动已发布界面。把示例中的对齐包路径换成第一条命令输出的路径，ANDROID_HOME、MARKETLAB_JAVA_HOME 使用上文工具位置。

```sh
./android/device-tests/build.sh
python3 android/tools/sign.py /路径/aligned.apk /tmp/MarketLab-device-check.apk "$MARKETLAB_JAVA_HOME/bin/keytool" "$ANDROID_HOME/build-tools/33.0.2/apksigner"
adb -e install -r downloads/MarketLab-Android.apk
adb -e install -r /tmp/MarketLab-device-check.apk
adb -e shell cmd connectivity airplane-mode enable
adb -e shell am instrument -w cn.zijing.marketlab.qa/.Check
adb -e shell cmd connectivity airplane-mode disable
```

测试到导出时，在系统文件选择器点「保存」，检查输出末尾的 PASS，并从「下载」打开新生成的报告。专门的检查包只进入测试模拟器，网站实际下载提供正式 App。
