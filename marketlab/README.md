# MarketLab · AI 金融市场实验室

在「柳园最终兵器」首页的「工具箱」点「AI 金融市场实验室」，进入同一个工作台。网页版固定在 2026 年 11 月 18 日，首页可切换沪深300、标普500和纳斯达克综合。总览列出六项实验及安卓版下载。整站使用现有中文导航与布局，无前端编译步骤。

## 如何开始

在 Mac 上双击本目录的「打开实验室.command」，或从展示站根目录运行 `python3 marketlab/server.py --open`。固定入口为 `http://127.0.0.1:8765/marketlab/index.html`。从服务终端按 Control-C 可关闭。也可直接双击展示站的 HTML 使用历史行情、数学模型、模拟交易和报告导出。使用同一浏览器和本机网址可稳定回到原记录。无痕窗口、清理站点数据、切换端口或改用文件预览会影响已有记录的可见性。

1. **市场观察**　选两个资产与日期区间，比较价格、相关系数和滚动相关性，查看截至所选日期可用的中美政策消息和原文。先点「保存到实验记录」，之后便能将观察写进报告。
2. **预测擂台**　选观察截止日，查看当时的行情，锁定自己对未来五个交易日上涨的概率，再比较基准、逻辑回归和可选 AI。历史练习可以揭晓结果。正式前瞻使用本机服务时钟和数据库单独记分；可选沪深300、标普500或纳斯达克综合，需要新近导入的完整、已获准使用的对应指数日线。后续导入覆盖第五个交易日的快照，再打开擂台，即可结算并复核。页面以指数点数展示三大主要市场，旧 ETF 可在历史归档中比较。具体窗口及封存规则见[正式前瞻说明](docs/正式前瞻.md)。
3. **量化研究**　选择标的、输入指标、模型、策略和互不重叠的训练与验证区间，运行并保存实验。查看概率误差、收益、回撤、净值和逐笔成交。只有收盘报价的汇率和债券收益率支持方向验证，有开高低收的标的另可回测交易。
4. **金融时光机**　设定起始日与模拟资金，开局后可以逐日或自动播放，提交买卖、撤单或记下观望理由。订单在下一交易日开盘处理。结束回合后查看账户、费用和持有基准，完成的回合可纳入报告。
5. **宏观沙盘**　分别修改 A 和 B 的政策利率、预期通胀、实际增长与风险偏好，对照股票现金流估值、固定息债券与现金购买力。页面列出折现公式及历史月度参照。按「保存此次推演」保存两组输入和结果。
6. **研究报告**　在需要的实验类别中各选一份记录，填入标题并保存。在同一页面重看历史报告，下载可离线阅读、打印的带图 HTML，或下载含逐笔凭据的 JSON。配置模型服务后，另可自愿生成基于已存证据的 AI 提要。

## 安卓手机试用

从工作台总览下载「安卓版安装包」，或将 `downloads/MarketLab-Android.apk` 传至 Android 8.0 或更高版本的手机后安装。安装后在「今日」点「更新行情与消息」。每个指数显示最近一个已收盘交易日，周末沿用上一交易日。离线可重看最近一次成功更新的内容。

「研究台」包含六项实验。行情更新后可点「载入新行情」。在「设置」选择模型厂商，应用会填好官方地址。选择模型，粘贴该厂商的 API Key 并保存，即可在「助手」提问。也可以读取当前账户可见的模型，或填写自己的兼容接口和接入点。助手可读行情、找公告、查原文并附出处。「每日更新」可设采集时间，也可单独开启每日 AI 简报并限制每日模型请求数。安卓会根据联网和省电状态安排执行。仅查看行情和新闻无需模型密钥。

## 数据与存储

- 网页版个人预览的沪深300含 938 个交易日，两个美股指数各含 974 个交易日。研究快照保存在个人目录。首次使用公开静态站可在所选指数下点载入，从行情源直接读取到自己的浏览器，也可导入有权使用的快照。网页回放、训练和验证都使用 11 月 18 日或之前的同标的数据。参见[沪深300来源](markets/cn/README.md)和[美国指数来源](markets/us/README.md)。
- 另有欧洲央行美元兑人民币交叉汇率、美国财政部十年期收益率、美联储 H.10 汇率和 41 条中美政策发布。各自按实际公布日期显示。旧的 2023–2024 年资产、模型及历史记录仍可复核。参见[历史档案](observe/README.md)和[旧示例来源](data/README.md)。
- Mac 用户双击与指数对应的「导入沪深300.command」、「导入标普500.command」或「导入纳斯达克综合.command」选择自己的 CSV 和保存位置，填入来源与使用许可。导入器在独立目录验证数据、运行 Python 模型、生成新快照和启动入口。科学计算依赖、日线格式与模型成绩见[模型与复现](docs/模型与复现.md)。
- 浏览器的 IndexedDB 保存人工练习和研究报告，localStorage 保存观察、回测、推演及完成的回合。时光机当前回合使用 sessionStorage。正式前瞻凭据与结算另存本机 SQLite，客户端提交时间或刷新操作不能覆盖它们。本机保存仅对这台设备有效。
- 数据导入和预生成的五日预测使用 Python、pandas、scikit-learn。可配置的量化实验直接在浏览器训练和回测，[量化方法](quant/README.md)附独立 Python 复算方式。[时光机说明](replay/README.md)描述交易与估值规则。服务器只监听本机回环地址，提供静态页面、正式预测与可选 AI 接口。

## 自愿开启 AI

在启动本机服务的环境中设置 `MARKETLAB_AI_KEY` 与 `MARKETLAB_AI_MODEL`，再重启。可选 `MARKETLAB_AI_BASE_URL` 默认为 `https://api.openai.com/v1`。兼容服务应支持 Chat Completions、JSON 对象及 max_tokens。凭据由服务端读取。调用费用依所选账户，未配置时页面显示「AI 服务未配置」，仍可使用结构化研究报告和其他实验。

预测 AI 使用截至所选日收盘的行情摘要及此前 90 天内最近三份已公布的政策消息。模型概率属于主观判断。报告 AI 仅能挑选实际实验中已有的事实与风险，显示的数字沿用原始记录。[报告 AI 接口](docs/报告AI接口.md)列出校验、缓存和请求限制。整个本机服务同一时间最多一笔模型请求，间隔至少五秒，每滚动 24 小时最多 20 次。数据缓存默认放在用户目录的 `.marketlab`，可用 `MARKETLAB_CACHE_DIR` 改变位置。
