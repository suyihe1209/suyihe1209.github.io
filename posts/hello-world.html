你好，我的个人博客上线了

随记

折腾了很久，终于把这块网上自留地支起来了。

为什么想写博客

理由其实很朴素：社交媒体太吵了，发什么都会被淹没在信息流里，过两天就找不着了。而一个自己的博客，写下的东西安静地待在那里，随时能翻回来。

说白了，就是想有个能让自己「认真写点东西」的地方。

打算写什么

  • 技术笔记——踩过的坑、调通的配置、学到的东西
  • 作品记录——音 MAD、设计、小工具这些折腾过的玩意儿
  • 日语歌词精讲——最认真的一件事，一句一句拆给你看

怎么搭起来的

目前是个纯静态站点，用最简单的 HTML + CSS + JS，零依赖、零构建。好处是够轻、够快、好维护。

// 写新文章：在 posts.js 里加一条，再建对应 html
const POSTS = [
  { slug: "hello-world", title: "...", date: "...", tag: "...", excerpt: "..." }
];
种一棵树最好的时间是十年前，其次是现在。

所以，就从这一篇开始吧。
