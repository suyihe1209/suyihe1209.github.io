MiniCode 代码编辑器

在手机上新建和编辑代码文件，查找替换、跳转到行，也可以导入已有文件，或把整个工作区备份带走。

在线打开 AI 试运行 → 下载安卓安装包（APK）↓ Android 7.0 及以上

让 AI 试运行一段代码

  1. 点「在线打开 AI 试运行」，或在安卓版编辑器中打开「AI 试运行」。想先写代码，可以先打开网页编辑器。
  2. 在编辑器设置里填写自己模型服务的 API Key。默认连接 DeepSeek。使用其他兼容服务时，先填接口地址和模型名，再填该服务的密钥。
  3. 对话框默认选中当前文件。代码还用到头文件或其他模块时，一并勾选。输入想测的数据，例如「给空数组，预计输出什么，为什么？」再点发送。
  4. AI 会根据发送的代码和输入推演结果，你可以继续追问是哪一行造成的。运行时间、外部文件和平台差异等，仍需在真实环境验证。

网页由浏览器直接连接你选的模型服务。密钥只在当前标签页使用，刷新或关闭后需要重新填写。安卓配置信息保存在本机。两端都在你发送时才提交所选代码，模型用量由你的服务商计费。

写下第一个文件

  1. 在安卓手机上下载安装包。已有 MiniCode 2.1.0 或 2.2.0 时，直接点开新版覆盖安装即可。
  2. 打开「资源管理器」，点加号，输入文件名，例如 hello.c。点编辑区输入代码，编辑器会按照文件后缀显示语法颜色。
  3. 在「命令面板」里输入文件名可以切换文件。搜索「转到行」并输入行号，可以直接跳到指定位置。点左侧「符号大纲」里的函数名或 Markdown 标题，也能跳到它所在的行。

让文件跟你走

编辑内容自动保存在 App 内。要把文件交给其他应用，打开「设置」里的「导出当前文件」，在系统文件选择器里指定位置。要继续编辑手机上已有的代码，用「导入文件」选择一份或多份。

换手机前，可以用「导出全部备份」把工作区保存为 JSON 文件。到另一台手机，用「导入文件」打开这份备份，并在确认框里核对恢复操作。模型密钥留在原设备。

用 AI 接着写

在「设置」里开启「AI 功能」，填写自己的 API Key 和模型名称。默认连接 DeepSeek，也支持提供兼容接口的服务。把光标放到要续写的位置，点「AI 续写」，核对建议后再插入。生成建议时，光标附近的代码会发送到你配置的服务。

编辑、查找和本地保存都可离线使用。要编译 C、执行 Python 或调试程序，请把文件导出到对应的运行环境。
