点一下 T800 看它出招，也可以拖住它，松手看它落地。

01 · 页面里只有一行标签

整个桌宠是 <t800-companion> 一个自定义元素。它用 Shadow DOM 把样式、设备像素比和内部结构锁在元素里：外部 CSS 改不动它的形状，它也不会把 3D 画布的样式泄漏给站点。换页面复用时只复制一行标签。

元素内部只有三块东西：一张 poster 立绘（首帧渲染前和降级时显示）、一个 canvas、一个铺满全图的透明 button。那个按钮不是装饰 —— 它承接指针拖拽和键盘焦点，所以桌宠可以被 Tab 聚焦、被方向键推着走，读屏软件也能读到它的说明。

02 · 点击才加载

首页不会在首屏拉这 6.3 MB。点了「召唤桌宠」之后，才创建 script 标签注入 tool-assets/t800-pet.js，并等待它的加载事件；加载失败会移除标签、把按钮文案复位，不会卡在「召唤中…」。

是否已注册用 customElements.get() 判断，反复点不会重复注入。收起时直接 remove()：disconnectedCallback 里中止 AbortController、取消 requestAnimationFrame、释放 GPU 资源，再点一次是干净重建。

03 · 渲染与省电

  • 每帧时间步长上限 80 ms，切到后台直接返回；visibilitychange 时恢复循环。
  • ResizeObserver 跟随容器尺寸，窗口缩放时重算落点，不会飘出屏幕。
  • 系统开启「减少动态效果」时命中 prefers-reduced-motion：冻结时间戳、跳过出场动画、关掉视线跟随 —— 动效不靠 JS 硬撑。

04 · 一套指针就能玩

  • 拖动：pointerdown 后用 setPointerCapture 接管指针，移动只改 translate 位置，不触发重排。
  • 松手：按最后几帧的速度换算冲击强度，播放落地缓冲；拖得越快，落地越沉。
  • 点击：在四个招式之间轮换，连点像在打一套连段。
  • 键盘：方向键微调，按住 Shift 一次推 40 px。
  • 视线：指针进入 230 px 半径才转头看你，离开自动回正。

05 · 动作是队列，不是一堆 if

外部只有一个入口 act(name)，合法值包括 idle、opening、wave、flurry、turn、bound、step、scan、land。sequence 会把六个动作塞进 remaining 队列逐个播放；arena 每次点击轮换四个招式。每组动作的时长由模型数据里的 performances[name].duration 决定，播完自动回到待机 —— 新增动作只要补一条模型数据，不用改循环。

06 · 已知限制

  • 6.3 MB 对移动网络仍然偏重，下一步可把引擎与模型拆开、按需加载。
  • 没有物理碰撞，只有视口边界钳制；桌宠之间也不会互相推挤。
  • 动作手感依赖模型里的关键帧，改动作要同时改数据与时长表。
