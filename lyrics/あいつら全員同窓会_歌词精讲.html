Lyrics Breakdown · 逐句精讲 #08

あいつら全員同窓会Aitsura Zenin Dousoukai ／ Inside Joke ／ PSO2:NGS 合作曲

ずっと真夜中でいいのに。（ずとまよ） ／ 作詞・作曲：ACAね ／ 2021-06-17 配信单曲（英题 Inside Joke）
PC 游戏《PSO2 ニュージェネシス》合作曲 ／ 目标水平：JLPT N4–N5 ／ 全曲逐句拆词 + 句法 + 口语缩约标注

先说实话：这首歌难在哪

句子骨架对你来说很友好——て形、ない形、た形、～し、～から基本都是 N5–N4 射程。真正卡人的是另外三样：

一、口语缩约（脱落）。歌里几乎全用口语收缩形：置いていった → 置いてった、飛んでいった → 飛んでった、終わっていく → 終わってく、探している → 探してる。中间那个「い」被吃掉是日语口语的常规操作，但你如果在字典里查「おいてった」一定查不到。这是听力第一杀手，值得单独记。

二、惯用句密集。当たり障りがない、道草を食う、下積み、空騒ぎ、命取り、棚に上げる、骨が折れる——这七家伙出现二十多处，而且全是日本初高中生就会、外国学习者没听过的那类。

三、ACAね 的造词。愛闇＝アイシャドウ、ジェメオス＝涂鸦双人组、ステンバイミー＝stand by me。这些不是你词汇量的问题，是作者故意难为读者。

建议路线：先把下面三张速查卡（口语缩约 / 惯用句 / 造词）过一遍 → 再逐句。顺序倒过来会被卡得很难看。

造词与当字：ACAね 的四个暗号

歌词写法实际读音是什么 / 为什么要这样写
愛闇アイシャドウ当字（当て字）。「愛」取音读 ai、「闇」管意思（＝影/暗）。整词＝eyeshadow 眼影。作者不写片假名，偏要用两个汉字拼出这个外来语，是ずとまよ的标志手法
ジェメオスジェメオス巴西圣保罗的涂鸦艺术家双人组 Os Gêmeos（葡萄牙语「双子」），作品遍布全球。配合下一句理解：这是 Street art 的语境
ステンバイミースタンド・バイ・ミーStand by me（站在我这边）。刻意写成「ステン」而不是标准的「スタンド・バイ・ミー」，压缩成一句话的长度
ファッションふぁっしょん外来语时装、穿搭＝自我表达的外壳这首歌里它不是「好看的衣服」，而是把情绪发散出去的容器——与上一句的「言葉」并列

口语缩约对照表（这首歌的听力命门）

歌里写的还原后脱落了什么
置いてった置いていった「い」脱落：〜てしまう/〜ていく 的口语音便。同型还有「置いてく」「置いてった」
飛んでった飛んでいった同上。注意不是「跳んでった」，动词是飛ぶ
終わってく終わっていく「いく」被压缩成「く」。〜ていく＝逐渐……下去（表示状态持续走向某方向）
探してる探しているている → てる，日常会话标准操作
わからなすぎわからなすぎる〜すぎる 变名词用法，后面直接挂「問題」
気づいてない気づいていない「ていない」→「てない」：进行/否定的口语压缩，全曲出现两次

七个惯用句，听不懂就整首垮一半

当たり障りがない
不得罪人、不痛不痒、没棱角。字面「没有会磕碰的地方」，形容一个人/一句话安全到毫无内容。
当たり障りのない儀式みたいな　→　像例行仪式一样毫无内容
道草を食う
在路上耽搁、闲逛再回来（原义：马在路上吃草耽误行程）。这首歌里说这是贅沢，即「能在路上瞎逛简直是奢侈」。
道草食って帰る　→　路上晃一圈再回家
下積み
在底层苦干、寂寂无闻地打基础（演艺圈/手艺行当的用词）。下積み正義＝「埋头苦干才是正义」那套说教。
下積み正義　→　吃苦当正义
空騒ぎ
からさわぎ。瞎起哄、白忙一场、虚张声势的热闹。『冷や水』不同——这是「六曜都是一个人在吵」的意思。
シャイな空騒ぎ　→　怯场却还要跟着起哄
命取り
いのちとり。致命的、要命的（不一定真死，指导致失败的致命偏差）。
小さな誤解が命取り　→　一点点误会就要命
棚に上げる
把自己的问题放到一边不予理会＝对自己宽容。完整形：自分のことは棚に上げる。
自分棚に上げすぎ　→　对自己太宽容了
骨が折れる
惯用句：费力气、辛苦。这首歌最后一行双关——字面是「笑到肋骨折」，惯用是「竭尽全力」。
あばらの骨が折れるまで　→　到肋骨折为止
没有匹配的句子，换个关键词试试。

四组替换：这首歌真正的修辞手法

位置第一次第二次作者想说什么
副歌 A／Bねばった戦績（せんせき）ねばった成績（せいせき）戦績＝战斗/游戏战绩（呼应 PSO2 合作），成績＝考试成绩。同一句滚两遍，把「战绩」和「成绩」焊在一起：在这个世界里，你的人生打算和你的战斗数据是一回事
最后一次副歌なりたい自分に絡まる電柱なりたい自分に絡まる連中全曲最重要的一处改动。前五遍副歌缠住「想成为的自己」的是电线杆（无生命的障碍物）；最后一次换成了连中（＝那群家伙、あいつら）。绕了三分钟才承认：挡路的一直是人
第三幕 对句どうでもいいから置いてったそうでもないから飛んでったどう↔そう、置いて↔飛んで。只换两个词，意义颠倒：前面是「无所谓，所以我放下了」，后面是「并非无所谓，所以我飞走」——上一句的逞强在这里被自己推翻
结尾两句言い切れることはないいい切れたことは自分に言い聞かせてること第一行用汉字「言い切れる」（断言），第二行改写成平假名「いい切れた」，让「いい（好）」乘机混进来：那些斩钉截铁的话，只是反复催眠自己「这样就好」

「ゆうもわな」——官方没给写法的一个词

「ジェメオスよりもゆうもわな落書きに」是全曲唯一官方歌词本没公布汉字写法的一句，目前有两派解读：

A 派（口语收缩说）：ゆうもわな ← 「言うほどでもない」（いうほどでもない）。いうほ→ゆうも、でもない→わな，被口胡一样的连贯发音压成一团。意思是「说了也没什么大不了 / 不值一提」，整句＝「比起 Os Gêmeos 的涂鸦，我更在意那种没人当回事的涂鸦」。

B 派（嵌字说）：「優（ゆう）も罠（わな）」——连「优秀」本身也是一种陷阱。这派与下一句「下積み正義」衔接更顺：正因为不迷信优秀，才有资格丢掉那套吃苦哲学。

本页保留假名原文不强行汉字化——这是负责任的做法。你只要记住它大概在说「不值一提 / 当回事就输了」即可。

这首歌能搬走的六个句型

① 置いてった／飛んでった（〜ていく 的口语缩约）
置いていった・飛んでいった → 置いてった・飛んでった。
公式：〜ていく → 〜てった／〜てく（中间的「い」脱落）。
你的句子：財布を忘れてった（我把钱包落那儿了）。
口语里极其常见，听力必考，但写作不要用。
② 〜たって／〜なくたって（＝ても／なくても）
誰を批判しなくたって → 「即使不去批判任何人」。
公式：动词ない形的く → たって（行かなくたって＝即使不去）。
比「ても」更口语、更带赌气感。
③ 名词止め（不用动词也能结句）
あいつら全員同窓会＝「那群人全跑去开同学会了」，句子最后是名词直接结句（名词止め），没有动词。
效果：留下画面、制造余味；抒情歌词和标题最爱用。
④ 〜でしかない（不过只是……）
想像は想像でしかないし → 「想象终究只是想象」。
公式：N／ナ形词干 + でしかない＝不过只是……（带贬义的限定）。
N3 语法，这首歌用得极熟：先承认局限，再顺势把所有东西拆台。
⑤ 棚に上げる（对自己宽容）
人のダメなとこばっか見つけて／指摘して、自分棚に上げすぎ → 「净盯着别人的毛病指指点点，对自己却过度宽容」。
完整形：自分のことは棚に上げる（把自己的问题搁到架子上不予理会）。
建议整句背下来，吐槽时的万能句。
⑥ 〜まで（到……为止）
あばらの骨が折れるまで → 「直到肋骨折」。
公式：动词辞书形 + まで＝直到……为止。
この曲的出现形式是夸张：笑的时间长度被夸张到身体出ダメージ为止。
