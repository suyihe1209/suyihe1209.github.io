山水天气

把天气放在手机桌面上。卡片的一侧留给你的照片，另一侧的河畔风景会随天气和昼夜变化。

下载安卓安装包（APK · 175 MB）↓ Android 6.0 及以上 · 经 GitHub Releases 外链

安装包体积较大，已从站点目录移出，走外链下载；离线演示时的本地副本不随本站发布。

第一次使用

  1. 用安卓手机下载上面的 APK，点开下载好的文件，按系统提示安装并打开「山水天气」。
  2. 准备自己的和风天气账号。在控制台的「设置」里复制专属服务地址（API Host），再到「项目管理」创建或打开项目，添加一个 API KEY 凭据。查看地址说明 · 查看密钥说明
  3. 在应用的「小组件设置」里点「天气服务」，把专属域名填进 API Host，把密钥填进 API Key，然后点「保存天气服务」。联网后，在预览里查看温度。要换城市，再点「天气城市」搜索。
  4. 回到手机桌面，长按空白处，打开「小组件」或「窗口小工具」，找到「山水天气」，把卡片拖到桌面。

放一张自己的照片

在应用里点「选择背景照片」，单指拖动照片，将想保留的人或风景对准左侧准星。双指可以缩放，点「保存照片」就会应用到桌面卡片。之后还能通过「调整照片位置」重新构图。

看一段天气风景

在应用里轻点天气卡片，就能全屏观看当前天气对应的山水短片。点「选景」可以在白天、夜晚之间切换，挑一场雨或一片晴空。看完再点「选景」，选择「返回当前天气」即可。

桌面温度一直显示空白？

先打开应用，确认手机能联网。「天气服务」里的地址和密钥需要来自同一个和风天气账号。重新填写后，回到预览确认天气，再查看桌面卡片。
